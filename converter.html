📖 Converter Teks Kitab → data.json

Copy-paste teks kitab Anda, lalu klik konversi

📌 Petunjuk Penggunaan:

  1. Copy semua teks kitab dari pesan yang Anda terima
  2. Tempelkan ke kotak teks di sebelah kiri
  3. Klik "Konversi ke JSON"
  4. Klik "Download data.json" untuk menyimpan file
  5. Simpan data.json di folder yang sama dengan index.html

⚠️ Catatan: Converter ini akan membagi teks berdasarkan bab secara otomatis. Setelah download, Anda bisa edit manual file JSON jika perlu.
